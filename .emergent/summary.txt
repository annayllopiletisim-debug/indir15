<analysis>**original_problem_statement:**
The user wants to build a modern, mobile-first coupon and deals website in Turkish.

**PRODUCT REQUIREMENTS:**

**Core Architecture:**
- The site structure is Categories -> Brands.
- Each brand has a dedicated page with 4 tabs: All, Coupon Codes, Discounts, and App Install (which can be toggled from the admin panel).
- Item counts must be displayed next to each tab label.

**SEO & Content:**
- SEO-friendly URL structure (e.g., ).
- Admin can edit meta title/description per page.
- Automatic H1/H2 structure.
- Schema markup for Coupons and Offers.

**Features:**
- **Homepage:** Hero slider (admin-managed), horizontally swipeable brand logo carousel.
- **Search:** A global, site-wide search for categories, brands, and deals. A Stores page should list all brands alphabetically.
- **Coupons/Discounts:**
    - Discounts must show an expiration date and a countdown timer.
    - Coupons must have an Active or Expired status badge.
    - **Revised Coupon Flow:** Clicking a coupon should first redirect to the brand's site with a UTM link, and then a modal should appear on the site to show the code.
- **App Install Tab:** Can be enabled/disabled per brand from the admin panel, with links for iOS and Android.
- **UTM Links:** Clickable items should redirect via UTM-enabled links, editable from the admin panel.
- **Social Sharing:** WhatsApp and Facebook share buttons with clear icons.
- **User Submissions:** A Submit a Coupon button linking to a Google Form.
- **Light/Dark Mode:** A user-toggleable theme saved in localStorage.
- **Category Navigation:**
    - **Desktop:** Horizontal menu under the header.
    - **Mobile:** Swipeable buttons above the hero slider.
- **Advanced Search:** Intent-based search (e.g., searching shoes shows shoe-related brands and categories). Admin should have a panel to map keywords to brands.
- **PDF Catalogs:** A Catalogs section where admins can upload PDF catalogs for brands (e.g., weekly grocery flyers). This includes a PDF viewer.
- **Logo Management:** Admin should upload logo files directly, not use external URLs, to ensure consistency and avoid broken links.
- **Expiring Soon Feature:** Highlight coupons/discounts expiring in the next 24 hours on the homepage and via a special badge.
- **Card Design Consistency:** All coupon and discount cards must follow a standard layout, with the expiration date always in the top-right corner.

**Admin Panel:**
- Simple, non-technical UI.
- **Dashboard:** Analytics showing click counts per brand, most clicked discounts, and most popular stores. The dashboard should have time filters (24h, 7d, 30d) and show conversion metrics.
- **CRUD Operations:** Full management for Categories, Brands, Coupons, Discounts, Hero Slides, and the new PDF Catalogs and Keyword Mappings.
- **Search:** Add search bars to the list pages for Brands, Coupons, and Discounts.

**Bug Fixes & UX Improvements:**
- The hamburger menu must be fixed and functional.
- The global search must be fixed and functional.
- The hero slider height should be reduced on mobile.
- The category pages must not be blank; they should list associated brands and deals.
- On the brand page, coupon/discount counts should be more visible (using badges, not small text).
- On the admin dashboard, the Most Popular Discounts list should show which brand the discount belongs to and have a direct link.
- Add at least 10 demo stores with sample data.

**User's preferred language**: Turkish
